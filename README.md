# Thalir - Study Roadmap Tracker

A study roadmap tracker where a tree grows as you complete topics. Plant a topic, tick it off when you finish, and watch your canopy fill with leaves.

## Live Demo
https://sabari7813.github.io/tracking-dairy/

## Features
- Add topics under any subject to build your own roadmap
- Tick topics off with a leaf-burst animation
- A tree that grows through 6 stages as your progress increases
- Progress ring showing completed topics
- Day streak, topics done today and total finished
- Heatmap of the last 7 weeks of activity
- Day-by-day history of completed topics
- Notes for every topic
- Data saved in your browser, nothing leaves your device

## Tech Stack
HTML, CSS, JavaScript (no frameworks, no backend)
- SVG used to draw the growing tree and progress ring
- localStorage used to save topics and history

## How to Run
Download index.html and open it in any browser. No installation needed.
